# SkillMem Agent V1 当前边界（Stage 3–5）

这是本机电商售后模拟系统和可复现实验工程，不是生产支付系统。订单来自合成夹具；身份 Header、员工共享 Key 仍是演示鉴权。Stage 3/4 已分别通过历史阶段验收；Stage 5 已运行完整冻结实验；Gate和证据见阶段报告。

## 已实现能力与不应夸大的部分

- **TaskMemory**：M/MS 使用 `state.py:SupportState/TaskMemory` 与 `memory.py`，保存当前订单、用户约束、带来源的工具事实、资格历史快照和任务状态。用户输入不成为 verified 事实，工具执行仍由原 Policy 重验。它是会话内结构化任务投影，不是长期用户画像、知识库或通用自然语言理解。
- **约束提取**：`merge_user_constraints` 使用有限中英文规则识别明确订单、金额及比较符；其他条件主要保存原话。未验证约束不能替代授权。复杂指代、跨句条件、隐含金额和矛盾仍可能被模型误解。没有宣称完整中文多轮任务通过。
- **Context**：`build_model_context` 构造派生模型输入，完整 checkpoint 不删除。工具调用与结果成组裁剪；可安全投影的长工具 JSON 做确定性压缩，关键规则、最新请求和结果组保留。大量不能丢弃的条件可能导致明确的 `context_budget_exceeded`，不是无限上下文方案。
- **Token Budget**：UTF-8 字节加封装余量是保守估算，涵盖系统、工具 Schema、Skill、TaskMemory、历史、输出预留和安全余量；不是 DeepSeek 精确 tokenizer，也不是计费 Token。真实用量来自 provider usage，缺失为 null；估算减少不能单独证明费用下降。
- **历史增长**：完整 checkpoint、观察去重标记和显式条件会随会话增长；目前没有数据库归档、会话生命周期回收或无限长度保证。
- **Skills**：MS 使用四个固定 Skill；同一模型通过 `select_skill` 选择后动态绑定 Schema，Guard 再校验允许列表。初始化读取全部本地 SOP，按需披露指模型只看到当前 Skill 正文，不是磁盘懒加载。不是插件市场、自动技能发现或多 Agent。
- **Skill 成本**：路由增加模型轮次、工具尝试和延迟，全部计入共同预算；8 工具场景不保证降本或提高成功率。`B1 + full_sop` 对照控制新增知识，不能把 SOP 知识收益直接归给路由。
- **未实现范围**：无独立 Planning 模块、Planner LLM、LLM 摘要、长期记忆、RAG、多 Agent、SFT/RL 或真实支付接入。TaskMemory 的进度字段不等于完整规划器；保留的 `context_summary` 字段也不表示已实现摘要。

## 持久化、恢复与并发

- **持久化范围**：同一文件路径下，SQLite 保存业务完整快照、退款/取消/工单幂等回执、审批决定与结果、执行次数及 LangGraph checkpoint。业务事务与 checkpoint 是两个提交边界，通过稳定业务回执处理跨边界重放；没有分布式事务或真实支付 Exactly Once 保证。`db_path=None` 是临时模式。
- **已有重启证据**：`tests/test_persistence.py` 覆盖独立子进程重启，以及退款事务提交后 `os._exit`、下一进程恢复审批。Stage 3/4 另有旧 checkpoint 迁移与审批恢复测试。没有测试主机断电、文件损坏、磁盘满、备份恢复、NFS 或多主机部署。
- **Stage 5 恢复夹具**：`evaluation.py:Approval.restart` 在同一进程关闭并重建 Service，保留数据库与模型对象；`failure_point` 注入一次恢复前/后异常，再以相同决定恢复一次。该实验不是操作系统进程崩溃实验，不得借用上述其他测试的证据扩大其含义。
- **应用并发**：一个 Service 实例串行其会话；不同实例/进程对同 DB/thread 使用 POSIX flock，业务写事务还由 SQLite 串行。锁文件暂不回收；全量业务快照和 SQLite 写竞争不适合大规模订单库。
- **评测夹具并发**：`evaluation.py:fixture_tools` 暂时替换构造器工具工厂，模块 RLock 覆盖所有评测 Service 构造，执行时使用各实例独立闭包。运行 benchmark 时，不应在同一进程并行启动未使用该锁的其他应用 Service；该限制不是应用本身必须禁用并发。
- **恢复语义**：审批决定写入后不可覆盖；相同 `approval_id` 与相同决定可恢复或返回已保存结果，冲突决定返回 409。非审批基础设施故障可用 `SupportService.retry_turn`。模型/工具终止可能使回复为 failed，但业务已经提交；必须查询真实业务状态与回执，不能按回复状态再次退款。
- **历史迁移**：B0 未持久化业务，不能从其 checkpoint 重建已发生退款。B1/M/MS 不应直接混用 B0 数据库。B1→M/MS 支持的旧状态恢复有专项测试，不是任意版本、任意损坏数据的自动迁移承诺。

## 执行限制与费用边界

- **工具协议**：B1/M/MS 每响应只执行一个合法调用；多调用返回全部匹配错误且零业务执行。未知工具、非法参数可在剩余预算内修正；丢失/重复 call ID 无法安全配对时明确终止。MS 还检查 Skill 允许列表，猜中工具名不绕过权限。
- **超时**：同步本地工具在进入/提交事务前检查截止时间，超时不提交副作用；不是可杀死任意阻塞 Python 函数的硬中断。模型 SDK 网络超时与 SQLite busy timeout 仍影响返回时间，5 秒工具配置不等于所有故障下 5 秒返回。
- **单轮预算**：默认每用户轮次 8 次模型、8 次工具尝试；Skill 控制步骤也消耗尝试。审批等待不消耗执行墙钟窗口，但恢复不重置次数。SDK 内部重试为 0，副作用无自动重试；这不是账户级限流或普遍美元上限。
- **批次预算**：Stage 5 脚本另外使用共享请求/费用账本，并在发出请求前预留上界；该脚本范围外的普通 CLI/API 不因此获得费用保护。服务商计费、模型可用性和价格随时间变化；冻结配置和价格记录只说明该次实验。

## 测量与安全声明

- **离线与在线分开**：规则模型、脚本模型、Mock SDK 测试验证机制和 Oracle；不能用其通过率代替真实 LLM 任务成功率。Stage 1 的三个真实服务端冒烟只证明有限链路；Stage 5 最终指标、实际请求/费用和失败归因由正式实验报告提供。
- **Oracle**：`evaluation.py:judge` 是唯一任务判定实现。runner 中查询要求真实工具证据和回复事实；写操作核查业务后置状态；Memory 指标使用回复与业务/工具证据，不要求 B1 也具有 TaskMemory。旧直接调用 `judge(..., events=None)` 保留兼容语义，不应拿它替代 runner 的证据检查。
- **文本限制**：数字等值、EUR 符号、部分英文日期格式及附近中英文否定有规则支持；政策、拒绝和澄清依赖明确短语、备选短语或问号。它不是语义评审器，可能漏判正确改写，也不能识别任意矛盾。冻结后不因 Final 失败改 Oracle 或提示。
- **SOP 范围**：当前 `sop_compliance` 仅表示“每次退款提议前有成功资格查询”。它不是四份 SOP 全项合规率。业务安全、审批匹配、真实工具证据和该软流程指标分别报告。
- **失败与不安全分开**：没有完成请求会失败，但不自动计为不安全副作用；额外、越权、不符合退款政策或账实不一致的业务变更单独记录。无法取得业务证据时保留 unknown，不能补 0。审批/记忆适用任务在模型未完成或初始化失败时仍保留计划分母。
- **故障覆盖**：Stage 5 工具故障只允许只读工具一次 TimeoutError，不对退款/取消等变更工具任意注入故障；已有执行恢复测试是补充证据，不意味着全面故障注入覆盖。
- **日志**：原始对话、模型返回和业务快照只放忽略目录；Key 过滤不是通用 PII 匿名化。公开导出仅限审查后的合成数据统计与摘要。日志写入失败不能触发业务重放。
- **部署**：未完成生产身份认证、密钥轮换、多租户隔离审计、隐私合规、灾备、真实订单/支付集成和容量验证。MIT 来源和开源许可保留不等于外部服务商使用条款审计。

## 已知判分缺陷与结论边界

冻结Final的50条未通过中，独立逐条审计确认：12条中文订单号词边界误拒、1条安全拒绝同义词漏配；6条正确使用订单但最终省略编号，不能据此断言失去订单记忆；2条安全拒绝满足但未给rubric要求的业务理由；其余29条为未完成/早期上下文未恢复。原始评分、源码、数据及哈希全部保留，没有对Final定向调参。未全面穷尽成功样本的语义假阳性，因此原通过率也不能简单称作真实成功率的严格下界。Memory Retention同样受输出规则约束。

M总Token高于B1，MS总Token又高于M。本实验不能支持“Skill省Token”或“Memory降低总成本”；长历史收益来自合成且明确控制的上下文，不等于开放域长期记忆能力。SOP100%仅对实际退款提议之前的资格检查，不能覆盖四份SOP的所有要求。模型服务可能升级，即使temperature=0与版本manifest一致，第三方复跑也不保证逐字相同。
